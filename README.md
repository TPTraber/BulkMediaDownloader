# BulkMediaDownloader

A simple wrapper for sk-zk's [streetlevel](https://github.com/sk-zk/streetlevel) package, providing a front and and simple CSV parsing.

## Getting Started

### Installing

* Download latest packaged project under [Releases](https://github.com/TPTraber/BulkMediaDownloader/releases)

## Package from Source

* Clone repo to local device
* Install dependencies
```
pip install -r requirements.txt
```
* Install pyinstaller
```
pip install pyinstaller
```
* Package into .EXE with pyinstaller
```
pyinstaller --onefile AppV2.py
```
